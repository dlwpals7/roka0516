# 🛰️ [프로젝트 제안서] 은하계 계산기 마스터 (Galactic Calc RPG)
> **Java 핵심 라이브러리, 기본 문법, 포맷팅, 정규표현식 및 객체지향 핵심 이론을 한 번에 마스터하는 통합 콘솔 토이 프로젝트**

---

## 1. 프로젝트 개요
- 단편적인 예제 풀이에서 벗어나, 입문 단계에서 필수적인 Java의 내장 클래스들과 객체지향 프로그래밍(OOP) 핵심 개념을 하나의 스토리라인(우주 탐험 RPG)에 유기적으로 결합하여 실전 구현 능력을 극대화합니다.

---

## 2. 프로젝트 시스템 아키텍처 (상속 & 다형성)
- **`CosmicEntity` (부모 클래스):** 공통 메소드 `performAction()` 정의
- **`SpaceMonster` / `SpaceMerchant` (자식 클래스):** 부모를 상속받아 오버라이딩(`@Override`) 구현
- **다형성(Polymorphism) 실습:** 하나의 부모 타입 변수(`CosmicEntity event`)에 무작위로 자식 인스턴스들을 할당해 제어함으로써 유연한 객체 지향 컴포넌트 설계를 연습합니다.

---

## 3. 스테이지별 기능 요구사항 및 기술 매핑

### 🔐 [스테이지 1] 우주선 보안 로그인 시스템
- **요구사항:** ID와 Password를 입력받아 대/소문자, 숫자가 포함된 8자 이상의 유효성을 검증합니다.
- **매핑 기술:** `Scanner`, `정규표현식`, 다중 `if-else` 분기문

### 👾 [스테이지 2] 현자 몬스터의 궤도 중력 수수께끼
- **요구사항:** 좌표 사이의 절대 거리, 크리티컬 확률, 중력 감쇠 공식을 적용해 정수형 최종 대미지를 산출합니다.
- **매핑 기술 (`Math` 클래스 전원 출동):** `abs()`, `random()`, `max()`, `min()`, `pow()`, `sqrt()`, `round()`, `floor()`, `ceil()`

### 💬 [스테이지 3] 외계 상인의 암호화된 비밀 거래소
- **요구사항:** 비정형 텍스트 데이터(`"Item:Shield/Price:500"`)를 파싱하여 장비를 구매하고 대화 로그를 누적 빌드합니다.
- **매핑 기술:** - `String` 메소드 12개 (`trim()`, `indexOf()`, `charAt()`, `substring()`, `equals()`, `equalsIgnoreCase()`, `toLowerCase()`, `toUpperCase()`, `replace()`, `replaceAll()`, `valueOf()`, `split()`)
  - `StringTokenizer`, `StringBuffer` (.append() 활용)

### 💰 [스테이지 4] 은하 연방 은행 (초고액 자산 연산)
- **요구사항:** 기본 데이터 타입 범위를 초과하는 은하계 화폐를 안전하게 복리 연산하고, 텍스트 정렬 대시보드를 출력합니다.
- **매핑 기술:** `BigInteger` (`.add()`, `.multiply()`), `포맷 서식자` (`%d`, `%,d`, `%-15s` 등)

---

## 4. 제어 흐름 구조 (Control Flow)
- **반복문 (`while` & `for`):** `while`문을 이용한 메인 키오스크 무한 루프 구현 및 `for`문을 이용한 턴제 전투/아이템 루프 제어
- **조건문 (`switch-case` & `if-else`):** 메뉴 분기를 위한 `switch-case`문과 세부 조건 검증을 위한 `if-else`문 적용
