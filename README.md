================================================================================
[토이 프로젝트 제안서] Text-Based Turn RPG: "Console Hero"
================================================================================

1. 프로젝트 개요
   - 프로젝트명: Console Hero (콘솔 히어로)
   - 개발 언어: JAVA (JDK 11 이상 권장)
   - 개발 환경: 이클립스, IntelliJ 또는 VS Code (콘솔 입출력 기반)
   - 목표: JAVA의 기본 문법(조건문, 반복문, 배열)을 복습하고, 
           클래스와 객체 지향 프로그래밍(OOP)의 핵심 개념을 실전 코드로 구현합니다.


2. 주요 핵심 기능 (복습 포인트)
   
   ▶ 플레이어 및 몬스터 클래스 설계 (Class & Instance)
      - 속성(필드): 이름, 체력(HP), 공격력, 방어력, 레벨, 경험치
      - 기능(메서드): attack(), takeDamage(), isAlive()
      - 복습 포인트: 생성자(Constructor)를 통한 초기화, 캡슐화(Getter/Setter) 적용

   ▶ 턴제 전투 시스템 (Loop & Conditional)
      - 플레이어와 몬스터가 한 번씩 공격을 주고받는 반복 구조 구현 (while문 활용)
      - 크리티컬 히트(확률적 치명타)나 회피 기능 추가 (Math.random() 활용)

   ▶ 보상 및 레벨업 시스템 (State Management)
      - 몬스터 처치 시 경험치와 골드 획득
      - 경험치가 일정 수치 이상 쌓이면 레벨업 (체력 및 공격력 상승)


3. 추천 클래스 구조 (설계 가이드)

   - Main 클래스
     * 역할: 게임의 시작점. 전체적인 게임 루프(메뉴 화면, 게임 종료 등)를 관리합니다.
     * 주요 개념: main 메서드, Scanner 입출력

   - Character 클래스
     * 역할: 플레이어와 몬스터의 부모 클래스. 공통 속성(HP, 공격력 등)을 가집니다.
     * 주요 개념: 상속 (Inheritance)

   - Player 클래스
     * 역할: Character를 상속받음. 레벨업, 경험치, 스킬 사용 기능을 가집니다.
     * 주요 개념: super 키워드, 메서드 확장

   - Monster 클래스
     * 역할: Character를 상속받음. 고블린, 오크 등 다양한 몬스터의 기틀이 됩니다.
     * 주요 개념: 다형성 (Polymorphism)

   - BattleManager 클래스
     * 역할: 전투 로직만 전담하는 클래스. 플레이어와 몬스터를 인자로 받아 싸우게 합니다.
     * 주요 개념: 객체 간의 상호작용, 참조 변수


4. 단계별 개발 로드맵 (추천 진행 순서)
   ※ 팁: 한 번에 다 만들려고 하지 말고, 상체부터 하체까지 붙여나가는 식으로 진행하세요!

   [1단계] 기본 뼈대 만들기 (1일차)
     - Character, Player, Monster 클래스 정의하기 (필드와 기본 메서드만 구현)
     - Main에서 플레이어 객체 하나 생성해서 스펙 출력해보기

   [2단계] 전투 로직 구현 (2일차)
     - BattleManager 클래스를 만들고, while문을 이용해 서로 치고받는 콘솔 로그 구현
     - 예시 출력: "용사가 고블린에게 15의 데미지를 입혔습니다! (고블린 HP: 25/40)"

   [3단계] 게임 루프 및 성장 요소 (3일차)
     - 몬스터가 죽으면 경험치를 얻고, 레벨업하는 로직 추가
     - Main에서 "1. 모험하기 | 2. 스테이터스 보기 | 3. 종료" 선택 메뉴 만들기

   [4단계] (선택/심화) 상속과 다형성 맛보기 (4일차)
     - Monster를 상속받는 Slime, Dragon 클래스를 만들기
     - 각 몬스터가 서로 다른 공격 메세지나 스킬을 쓰도록 오버라이딩(@Override) 해보기
